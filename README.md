# Jasmine's Codex Skills Portfolio

这是一个由 35 个个人 Codex Skills 组成的作品集，覆盖投资研究、机器人 GTM、求职决策与企业内容生产。每个目录都是一篇独立的作品说明，包含功能介绍、使用方法和可公开的源文件。

## 作品集概览

- 35 个独立 Skills
- 4 个能力领域
- 每个 Skill 均保留 `SKILL.md` 源文件
- 含参考资料、脚本或模板的 Skill 保留可公开部分

## 关于公开版本

本仓库是作品集版本，不是本机工作目录的逐字镜像。个人简历、真实本地路径、公司术语库、内部品牌模板和二进制演示文稿已被排除或替换为公开示例，以避免泄露个人或公司信息。仓库未附开放源代码许可证；公开可见不代表自动授权复制或商业使用。
