# 客户需求与痛点分析

## Skill 名称
客户需求与痛点分析 Skill

## 适用场景
用于拆解目标客户在某个机器人应用场景中的真实需求、痛点、购买决策链、付费意愿和销售阻力。

## 输入字段模板
```text
目标客户：
使用者/影响者/决策者：
应用场景：
产品形态：
地区：
报告用途：
已有客户信息：
```

## 分析框架
| 模块 | 分析要点 |
|---|---|
| 工作流 | 当前任务怎么完成、谁负责、频次、KPI |
| 痛点 | 成本、效率、安全、质量、体验、合规、招工 |
| 需求优先级 | 必须解决、锦上添花、展示型需求 |
| 决策链 | 使用者、技术评估、预算方、采购、最终拍板人 |
| 购买标准 | 性能、稳定性、价格、交付、售后、安全责任 |
| 阻力 | ROI 不清、替代人工敏感、部署复杂、可靠性担忧 |
| 验证问题 | 客户访谈问题和证据清单 |

## 输出格式
```markdown
## 结论先行
| 判断 | 结论 | 证据/假设 |

## 客户工作流与痛点地图
| 流程 | 当前做法 | 痛点 | 机器人机会 |

## 购买决策链
| 角色 | 关注点 | 影响力 | 应对信息 |

## 需求优先级
| 需求 | 类型 | 付费意愿 | 验证问题 |

## 销售风险与异议处理
```

## 质量检查标准
- 必须区分用户、买单方、影响者和采购方。
- 痛点要能映射到产品功能或商业价值。
- 明确哪些需求是刚需、哪些是展示型。
- 输出客户访谈问题，用于验证判断。

## 可复用 prompt
```text
请作为机器人公司 GTM 和产品市场负责人，分析以下客户在机器人应用场景中的需求与痛点。要求从客户工作流出发，拆解决策链、购买标准、付费意愿、主要异议和验证问题。输出中文表格化报告。

输入：
{输入字段}
```

## 示例输入
```text
目标客户：连锁康养机构
使用者：护理员、老人、运营院长
场景：康养陪伴与夜间巡房
产品形态：人形/移动服务机器人
用途：客户沟通
```

## 示例输出
```markdown
## 客户工作流与痛点地图
| 流程 | 当前做法 | 痛点 | 机器人机会 |
|---|---|---|---|
| 夜间巡房 | 护理员定时巡查 | 人手紧张、记录不完整 | 辅助提醒、异常上报、巡房记录自动化 |
```
