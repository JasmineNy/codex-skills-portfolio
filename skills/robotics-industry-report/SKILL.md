# 行业报告生成

## Skill 名称
行业报告生成 Skill

## 适用场景
用于生成面向内部决策、客户沟通、产品规划或投资人材料的完整机器人行业/场景分析报告。

## 输入字段模板
```text
报告主题：
目标读者：
应用场景：
产品形态：
地区：
报告用途：
篇幅：短版 / 标准 / 深度
已有资料：
```

## 分析框架
| 章节 | 内容 |
|---|---|
| 一页结论 | 机会、风险、建议、优先级 |
| 场景与客户 | 工作流、客户类型、痛点、预算 |
| 市场空间 | 测算逻辑、假设、数据缺口 |
| 竞品格局 | 直接竞品、替代方案、差异化 |
| 商业化 | 商业模式、ROI、GTM、渠道 |
| 产品启示 | 必备能力、MVP、路线图建议 |
| 风险与验证 | 技术、交付、政策、财务、市场 |

## 输出格式
```markdown
# {报告标题}
## 1. 一页结论
## 2. 场景与客户画像
## 3. 市场空间与机会判断
## 4. 客户需求、痛点与采购链
## 5. 竞品与替代方案
## 6. 商业模式、ROI 与 GTM 路径
## 7. 产品定位与路线图建议
## 8. 风险、假设与数据缺口
## 9. 下一步行动
```

## 质量检查标准
- 第一页能支持决策，不只是摘要。
- 每章都有“所以怎么办”的建议。
- 市场、客户、竞品、ROI、GTM 之间逻辑一致。
- 关键结论有证据、假设或验证动作。

## 可复用 prompt
```text
请作为机器人公司产品市场与商业化负责人，生成一份中文行业/场景分析报告。报告要服务于{报告用途}，结论先行，多用表格，覆盖市场空间、客户需求、采购链、竞品格局、商业模式、ROI、GTM 路径、产品建议、风险和数据缺口。不确定内容标注“需进一步验证”。

输入：
{输入字段}
```

## 示例输入
```text
报告主题：人形机器人在零售导购场景的商业化机会
目标读者：管理层
地区：中国
篇幅：短版
```

## 示例输出
```markdown
## 1. 一页结论
| 问题 | 结论 |
|---|---|
| 是否优先进入 | 不建议作为近期核心商业化场景，建议作为品牌展示/联合营销场景保留 |
| 原因 | 导购价值可感知但 ROI 难闭环，门店环境复杂，客户更可能为营销效果而非导购效率付费 |
```
