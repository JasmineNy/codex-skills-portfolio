# 解决方案包装

## Skill 名称
解决方案包装 Skill

## 适用场景
用于把机器人产品能力包装成客户可理解、可采购、可试点的行业解决方案或客户方案。

## 输入字段模板
```text
解决方案名称：
目标客户/场景：
客户痛点：
我方产品能力：
部署环境：
报告用途：客户材料 / 内部方案 / 销售支持
约束条件：
```

## 分析框架
| 模块 | 分析要点 |
|---|---|
| 方案定位 | 一句话说明解决谁的什么问题 |
| 场景包 | 核心任务、可选任务、暂不承诺任务 |
| 能力模块 | 机器人本体、AI、后台、集成、运维 |
| 部署路径 | 勘测、配置、试运行、验收、运营 |
| 成功指标 | 业务、技术、体验、运维指标 |
| 商业包装 | 试点包、标准包、增值服务 |
| 风险边界 | 安全、责任、环境、数据、售后 |

## 输出格式
```markdown
## 方案一句话
## 客户价值
| 痛点 | 方案能力 | 业务价值 | 验证指标 |

## 方案模块
| 模块 | 内容 | 是否标配 |

## 部署与试点计划
| 阶段 | 周期 | 交付物 | 验收标准 |

## 商业包装
## 边界与风险
```

## 质量检查标准
- 方案必须可销售、可交付、可验收。
- 明确哪些能力不承诺，避免过度包装。
- 成功指标要能用于试点验收。
- 客户价值要对应痛点和业务指标。

## 可复用 prompt
```text
请作为机器人公司解决方案产品市场负责人，把以下产品能力包装成面向客户的解决方案。要求输出方案一句话、客户价值、模块构成、部署流程、试点计划、验收指标、商业包装和风险边界。中文商务风格，避免空泛宣传。

输入：
{输入字段}
```

## 示例输入
```text
解决方案名称：智慧展厅人形机器人接待方案
目标客户：企业品牌展厅
客户痛点：讲解人力不足、互动形式单一、展示科技感
产品能力：语音交互、路线导览、定制讲解、后台内容管理
```

## 示例输出
```markdown
## 方案一句话
面向企业品牌展厅的机器人接待与讲解方案，用人形机器人承担迎宾、定点讲解和互动问答，提升展厅科技感并降低高峰接待压力。
```
