# 产品定位与差异化分析

## Skill 名称
产品定位与差异化分析 Skill

## 适用场景
用于定义机器人产品在目标场景中的定位、价值主张、差异化卖点、竞品叙事和客户沟通信息。

## 输入字段模板
```text
产品/方案：
目标客户：
目标场景：
主要竞品/替代方案：
核心能力：
报告用途：
```

## 分析框架
| 模块 | 分析要点 |
|---|---|
| 目标细分 | 谁最需要、谁最愿意付费、谁能最快落地 |
| 定位句 | 为谁、解决什么问题、凭什么不同 |
| 差异化 | 功能、性能、成本、交付、生态、服务、品牌 |
| 价值主张 | 决策者、使用者、技术方、财务方分别表达 |
| 证据链 | 数据、案例、Demo、认证、客户背书 |
| 风险 | 差异化是否真实、可持续、客户是否在意 |

## 输出格式
```markdown
## 定位结论
| 项目 | 建议 |

## 目标细分与取舍
| 细分客户 | 适配度 | 理由 | 是否优先 |

## 价值主张
| 受众 | 关心点 | 话术 | 证据 |

## 差异化矩阵
| 维度 | 我方 | 竞品/替代方案 | 客户价值 |

## Messaging
```

## 质量检查标准
- 定位句必须具体到客户、场景、价值和差异点。
- 不把技术参数直接当作客户价值。
- 每个卖点都要配证据或验证计划。
- 明确哪些卖点不适合作为主叙事。

## 可复用 prompt
```text
请作为机器人公司产品市场负责人，为以下产品/方案做定位与差异化分析。要求输出定位句、目标细分取舍、价值主张、差异化矩阵、客户话术和证据链。结论先行，避免空泛营销语。

输入：
{输入字段}
```

## 示例输入
```text
产品/方案：人形机器人开放开发平台
目标客户：高校、科研院所、开发者生态伙伴
竞品/替代方案：四足机器人平台、协作机械臂平台
用途：产品规划
```

## 示例输出
```markdown
## 定位结论
为需要开展具身智能研究和真实人机交互验证的高校/科研团队，提供可二次开发的人形机器人平台；差异化不应只强调硬件自由度，而应强调开放接口、实验复现、课程/科研支持和服务响应。
```
