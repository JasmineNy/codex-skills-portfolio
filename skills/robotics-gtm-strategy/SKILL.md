# GTM策略设计

## Skill 名称
GTM 策略设计 Skill

## 适用场景
用于为机器人产品或场景设计进入市场路径，包括 ICP、试点设计、销售动作、渠道合作、定价包装、转化漏斗和阶段性目标。

## 输入字段模板
```text
产品/方案：
目标场景：
目标客户：
地区：
当前阶段：概念 / Demo / 试点 / 商用 / 规模化
报告用途：
资源约束：
```

## 分析框架
| 模块 | 分析要点 |
|---|---|
| ICP | 最优首批客户画像、预算、痛点、可复制性 |
| Beachhead | 先打哪个子场景，为什么 |
| 价值主张 | 对决策者、使用者、技术评估方分别表达 |
| 销售路径 | 线索、拜访、Demo、试点、采购、复购 |
| 试点设计 | 周期、范围、成功指标、转商用条件 |
| 渠道伙伴 | 集成商、行业 ISV、设备商、园区/集团客户 |
| 阶段目标 | 30/90/180 天动作和指标 |

## 输出格式
```markdown
## GTM 结论
| 选择 | 建议 | 理由 |

## ICP 与首批客户
| 客户类型 | 进入理由 | 排除条件 |

## GTM 路径
| 阶段 | 目标 | 关键动作 | 指标 |

## 试点包设计
| 项目 | 建议 |

## 风险与应对
```

## 质量检查标准
- 有明确首批客户，而非“所有行业都可做”。
- 试点成功指标可量化或可验收。
- GTM 动作要落到 30/90/180 天。
- 说明不做哪些客户或场景。

## 可复用 prompt
```text
请作为机器人公司 GTM 负责人，为以下产品/场景设计进入市场策略。要求明确 ICP、首选子场景、价值主张、销售路径、试点包、渠道伙伴、30/90/180 天动作和指标。输出中文商业报告，结论先行。

输入：
{输入字段}
```

## 示例输入
```text
产品/方案：人形机器人导览互动方案
目标场景：文旅展陈
目标客户：科技馆、博物馆、品牌展厅
当前阶段：可 Demo
地区：中国
```

## 示例输出
```markdown
## GTM 结论
| 选择 | 建议 | 理由 |
|---|---|---|
| 首选客户 | 企业品牌展厅优先于公共博物馆 | 决策链更短，展示预算更灵活，容错率更高 |

## 试点包设计
| 项目 | 建议 |
|---|---|
| 周期 | 4-6 周 |
| 成功指标 | 日均互动次数、客户满意度、故障恢复时间、内容更新效率 |
```
