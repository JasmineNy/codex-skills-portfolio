# Build X-Humanoid Presentations

> Skill ID: `build-x-humanoid-presentations` · Category: 企业内容与品牌传播

## 功能说明

基于公司模板制作内部汇报或外部演示 PPT，并执行数据逻辑、保密与版式检查。

## 适合解决的问题

当用户请求与上述功能范围匹配的任务时，Codex 可读取本目录的 `SKILL.md`，按照其中的输入、步骤、质量控制和输出规范执行。

## 使用方法

1. 将本目录复制到 Codex 的个人或项目 Skill 目录。
2. 在对话中使用 `$build-x-humanoid-presentations` 显式调用，或让 Codex 根据 description 自动匹配。
3. 如本 Skill 含 `references/`、`scripts/` 或 `assets/`，请保留相对目录结构。
