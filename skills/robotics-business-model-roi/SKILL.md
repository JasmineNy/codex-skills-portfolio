# 商业模式与ROI测算

## Skill 名称
商业模式与 ROI 测算 Skill

## 适用场景
用于评估机器人产品在某个客户场景中的收费方式、客户 ROI、TCO、回本周期、单位经济模型和商业可持续性。

## 输入字段模板
```text
产品/方案：
目标客户/场景：
部署规模：
价格/成本假设：
替代对象：
地区：
报告用途：
已有数据：
```

## 分析框架
| 模块 | 分析要点 |
|---|---|
| 商业模式 | 买断、租赁、RaaS、项目制、服务费、分成 |
| 客户收益 | 人工节省、效率提升、收入增量、安全/合规/体验价值 |
| 客户成本 | 设备、软件、部署、维护、培训、运营、停机 |
| ROI | 年化收益、TCO、回本周期、敏感性分析 |
| 我方经济性 | 毛利、交付成本、运维成本、规模化风险 |
| 定价建议 | 入门包、标准包、旗舰包、试点价、转商用条件 |

## 输出格式
```markdown
## 结论先行
| 商业判断 | 结论 | 关键假设 |

## ROI 测算
| 项目 | 数值/范围 | 说明 |

## 商业模式对比
| 模式 | 客户接受度 | 我方现金流 | 风险 | 建议 |

## 敏感性分析
| 变量 | 乐观 | 基准 | 保守 | 影响 |

## 数据缺口与验证方式
```

## 质量检查标准
- 不用没有来源的单点数字冒充事实。
- 必须写清公式、假设和敏感变量。
- 同时看客户 ROI 和我方单位经济性。
- 给出可落地的定价/试点建议。

## 可复用 prompt
```text
请作为机器人公司商业化负责人，为以下场景做商业模式与 ROI 测算。要求列出买断、租赁/RaaS、项目制等模式的优劣，给出客户 ROI、TCO、回本周期、敏感性分析和定价建议。所有缺失数字用假设区间，并标注“需进一步验证”。

输入：
{输入字段}
```

## 示例输入
```text
产品/方案：仓储搬运机器人
目标客户/场景：中型电商仓
部署规模：5 台
替代对象：人工搬运与拣选辅助
用途：内部决策
```

## 示例输出
```markdown
## ROI 测算
| 项目 | 基准假设 | 说明 |
|---|---:|---|
| 人工替代/增强收益 | 需进一步验证 | 需获取班次、人效、工资和峰谷波动 |
| 运维成本 | 需进一步验证 | 包含远程监控、备件、现场维护 |

## 建议
先用 8-12 周 RaaS 试点验证作业稳定性和人效提升，再决定买断或年租。
```
