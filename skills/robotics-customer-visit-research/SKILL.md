# 客户拜访前研究

## Skill 名称
客户拜访前研究 Skill

## 适用场景
用于拜访客户、销售会议、方案共创、试点沟通前，快速准备客户背景、需求假设、提问清单、会议议程和推进策略。

## 输入字段模板
```text
客户名称：
客户行业：
拜访对象/角色：
拟讨论场景：
我方产品/方案：
会议目标：
已有信息：
```

## 分析框架
| 模块 | 分析要点 |
|---|---|
| 客户画像 | 业务、组织、门店/工厂/园区、数字化基础 |
| 需求假设 | 可能痛点、预算来源、当前方案 |
| 决策链 | 参会人角色、影响力、关心点 |
| 会议策略 | 开场、Demo、问题、成功标准、下一步 |
| 提问清单 | 业务痛点、流程数据、预算采购、技术约束 |
| 风险 | 不适配点、异议、信息缺口 |

## 输出格式
```markdown
## 拜访目标与策略
| 项目 | 内容 |

## 客户需求假设
| 假设 | 依据 | 需验证问题 |

## 会议议程
| 时间 | 环节 | 目标 |

## 提问清单
| 类别 | 问题 | 目的 |

## 异议与回应
## 会后推进动作
```

## 质量检查标准
- 提问必须能帮助判断预算、痛点、决策链或试点条件。
- 不要把拜访材料写成产品宣传稿。
- 输出明确会后推进路径。
- 未知客户信息标注“需进一步验证”。

## 可复用 prompt
```text
请作为机器人公司 BD / GTM 负责人，为以下客户拜访做会前研究。输出客户画像、需求假设、会议议程、提问清单、可能异议和会后推进动作。重点服务于发现真实需求和推动试点/商机。

输入：
{输入字段}
```

## 示例输入
```text
客户名称：某大型汽车零部件工厂
拜访对象：生产负责人、自动化负责人
拟讨论场景：产线巡检和物料转运
会议目标：判断是否适合试点
```

## 示例输出
```markdown
## 提问清单
| 类别 | 问题 | 目的 |
|---|---|---|
| 流程 | 当前巡检频次、路线、异常处理是谁负责？ | 判断任务边界 |
| 经济性 | 单班人员配置和加班成本如何？ | 建立 ROI 假设 |
```
