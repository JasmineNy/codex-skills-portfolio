# 竞品分析

## Skill 名称
竞品分析 Skill

## 适用场景
用于对机器人公司、产品、解决方案或替代方案进行竞品分析，支持产品定位、销售应对、投资人材料和市场进入判断。

## 输入字段模板
```text
竞品/公司名单：
目标场景：
对标产品：
地区：
分析用途：销售应对 / 产品规划 / 投资人材料 / 战略判断
已有资料：
关注维度：
```

## 分析框架
| 维度 | 分析内容 |
|---|---|
| 公司背景 | 融资、团队、战略重心、客户类型 |
| 产品能力 | 硬件形态、运动能力、感知交互、任务能力、开放性 |
| 商业进展 | 客户案例、交付数量、试点转化、价格与交付模式 |
| GTM | 目标行业、渠道、合作伙伴、销售打法 |
| 优劣势 | 技术、成本、供应链、品牌、生态、服务 |
| 我方应对 | 避免正面竞争、差异化、销售话术、产品补齐 |

## 输出格式
```markdown
## 一页结论
| 竞品 | 威胁等级 | 核心优势 | 核心短板 | 我方应对 |

## 对比矩阵
| 维度 | 我方 | 竞品 A | 竞品 B | 结论 |

## 竞品 GTM 与商业化判断

## 差异化策略
| 战场 | 不建议打法 | 建议打法 | 依据 |

## 需进一步验证
```

## 质量检查标准
- 区分“直接竞品”“替代方案”“潜在进入者”。
- 不只罗列参数，要解释对客户购买决策的影响。
- 竞品未知信息标注“需进一步验证”。
- 必须输出我方差异化和销售应对建议。

## 可复用 prompt
```text
请作为机器人公司产品市场/竞品分析负责人，对以下竞品做商业化导向分析。不要停留在参数罗列，要判断客户为什么会买、竞品如何卖、我方如何应对。输出中文表格化报告，并标注假设和需进一步验证的信息。

输入：
{输入字段}
```

## 示例输入
```text
竞品/公司名单：Figure、Agility Robotics、优必选
目标场景：工业制造搬运与巡检
对标产品：人形机器人
地区：全球/中国
用途：投资人材料
```

## 示例输出
```markdown
## 一页结论
| 竞品 | 威胁等级 | 核心优势 | 核心短板 | 我方应对 |
|---|---|---|---|---|
| Figure | 高 | 资本、头部客户、AI 叙事强 | 真实规模化交付仍需验证 | 避免直接拼通用能力，强调可交付场景和本地服务 |
```
